# Задание 1 · Профиль клиента: календарь напоминаний

## Постановка

Служба уведомлений рассылает клиентам поздравления с днем рождения,
счета в конце расчетного месяца и ежедневные сводки. Профиль клиента
(`src/ClientProfile.java`) собран из полей разной природы — поэтому у
каждого поля свой тип `java.time`:

1. `MonthDay birthday` — день рождения: год неизвестен;
2. `YearMonth billingMonth` — расчетный месяц: день месяца неизвестен;
3. `LocalTime digestAt` — время ежедневной сводки: дата неизвестна;
4. `ZoneId zone` — зона офиса клиента.

Реализуйте четыре метода в `src/Task1.java`:

1. `birthdayIn(MonthDay, Year)` — дата дня рождения в конкретном году;
2. `billingEnd(YearMonth)` — последний день расчетного месяца;
3. `digestInstant(LocalDate, LocalTime, ZoneId)` — момент отправки сводки;
4. `isBirthday(MonthDay, LocalDate)` — совпадают ли месяц и день.

## Указания

- Тип не должен заставлять выдумывать неизвестные поля: день рождения
  без года — это `MonthDay`, а не `LocalDate` с фиктивным годом.
- `MonthDay.atYear` бросает `DateTimeException` на 29 февраля
  невисокосного года — сначала проверьте `isValidYear` и бросьте
  `IllegalArgumentException` сами.
- `YearMonth.atEndOfMonth` сам знает про високосный февраль.
- Сводка: соберите `LocalDateTime` из даты и времени (`atTime`), затем
  превратите его в момент через зону клиента (`atZone(...).toInstant()`).
- Сравнение с днем рождения: `MonthDay.from(LocalDate)`.
