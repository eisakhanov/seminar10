# Задание 2 · Попадание события в сутки региона

## Постановка

Дано: события ночной смены — моменты `Instant` (см. `src/ShiftEvents.java`),
регион отчета `Europe/Berlin` и календарные сутки `2026-05-12`.

1. `dayStart(LocalDate, ZoneId)` — начало суток в регионе;
2. `dayEnd(LocalDate, ZoneId)` — начало следующих суток;
3. `contains(Instant event, LocalDate day, ZoneId zone)` — попадает ли
   событие в календарные сутки региона. Интервал полуоткрытый:
   `[start, end)` — не раньше начала и строго раньше конца.

Контроль в `main` проверяет границы интервала на шести событиях.

## Указания

- Оба конца берите в одной зоне: `day.atStartOfDay(zone)` и
  `day.plusDays(1).atStartOfDay(zone)` — тогда переходы DST не сломают
  границы суток.
- Сравнивайте моменты, а не строки: `toInstant()` и `isBefore`.
- Подумайте, почему интервал именно полуоткрытый: полночь следующих
  суток принадлежит уже следующим суткам, а не этим.

## Ожидаемый вывод

```
данные: 6 событий, регион Europe/Berlin, сутки 2026-05-12
OK   dayStart
OK   dayEnd
OK   e1-до-начала
OK   e2-граница-начала
OK   e3-внутри
OK   e4-внутри
OK   e5-граница-конца
OK   e6-после-конца
дополнительно: в сутки попало 3 события из 6
```
