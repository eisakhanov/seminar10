# Практика к лекции 10: Java Time API

Пять заданий по материалам лекции 10. Задания соответствуют слайдам
«Практическое задание 1–5» презентации и разбираются на занятии.

Каждая папка `task-NN-*` самодостаточна:

- `README.md` — постановка, указания и контроль;
- `src/` — скелет: записи предметной области, фиксированные данные и
  файл `TaskN.java` с методами `TODO` и автоматическим контролем в `main`.

## Требования

- Java 17+ (проверялось на JDK 21);
- сборщик не нужен — только `javac` и `java`.

## Как работать

1. Прочитайте `README.md` задания.
2. Скомпилируйте и запустите:

```
javac -encoding UTF-8 -d out src/*.java
java -cp out Task1
```

Флаг `-encoding UTF-8` обязателен: в исходниках есть русский текст.

3. Реализуйте методы, помеченные `TODO`. Запускайте контроль снова после
   каждого шага: `main` печатает `OK` для верных проверок и `FAIL` с
   ожидаемым значением для неверных.
4. Задание выполнено, когда все проверки — `OK`.

Пока `TODO` не реализованы, контроль печатает `FAIL ... реализуйте TODO` —
это нормальное состояние скелета.

## Задания

| Папка | Задание | Тренирует |
|---|---|---|
| `task-01-types` | Профиль клиента: календарь напоминаний | `MonthDay`, `YearMonth`, `LocalTime`, переход локального значения в момент через `atZone` |
| `task-02-interval` | Попадание события в сутки региона | полуинтервал `[start, end)`, `atStartOfDay` |
| `task-03-dst` | Gap и overlap в Europe/Berlin | `getValidOffsets`, `withEarlierOffsetAtOverlap`/`withLaterOffsetAtOverlap` |
| `task-04-analytics` | Задержки ответов сервиса | свертки `Duration`, среднее с округлением вниз, `Optional`, группировка по дню недели, `DateTimeFormatter` |
| `task-05-scheduler` | Расписание встреч распределённой команды | `Clock.fixed`, расписание по `LocalDate` (`plusWeeks`), локальное время момента в разных зонах |
